# FITLOG 🏋️

FITLOG is a modern workout planning web application that helps users explore workouts, save exercises for later, create a daily workout plan, and track completed exercises.

## 🚀 Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* React Context API
* React Toastify
* Lucide React
* Next/Image

## ✨ Key Features

### 1. 🏋️ Workout Library

Users can browse different workouts with useful information such as equipment, duration, calories burned, and rating.

### 2. 🔖 Save Workouts

Users can save their favorite workouts for later and manage them from the **Saved** section.

### 3. 📋 Today's Workout Plan

Users can add workouts to their **Today's Plan** and manage their daily workout list from one place.

### 4. ✅ Workout Completion Tracking

Users can mark workouts as completed and easily identify which exercises they have already finished.

### 5. 📊 Workout Statistics & Sorting

The My Plan page displays total exercises, workout duration, and calories. Users can also sort workouts by **Duration, Calories, or Rating**.

## 📱 Responsive Design

FITLOG is designed to provide a smooth experience across desktop, tablet, and mobile devices.

## 🎯 Project Goal

The main goal of FITLOG is to make workout planning simple, organized, and easy to manage through a clean and modern interface.
